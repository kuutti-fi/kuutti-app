# Code of Conduct

Kuutti adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text at that address applies to everyone who takes part in this project: in issues, pull requests, discussions, reviews, and anywhere else a person speaks for or within the project.

In short: be considerate and respectful, assume good faith, welcome people of every background and identity, and keep criticism about the work. Harassment, personal attacks, sexualised language or imagery, and publishing someone's private information are not acceptable here.

Kuutti is a dating service built on bank-verified identity. Contributors will sometimes handle reports, screenshots or data about real people. Treat all of it as confidential, never post it in a public issue, and follow [SECURITY.md](SECURITY.md) for anything that looks like a vulnerability.

## Reporting

Report a problem privately to the organisation's owners: [@superseacat](https://github.com/superseacat), [@juusohe](https://github.com/juusohe) or [@OlliKiljunen](https://github.com/OlliKiljunen), through the contact on their GitHub profile. If your report concerns one of them, write to another. A dedicated address replaces this list when the project domain has mail.

Every report is read, kept confidential, and answered. The owners decide on the response using the enforcement guidelines of the Contributor Covenant: a correction, a warning, a temporary ban, or a permanent ban from the project's spaces.
