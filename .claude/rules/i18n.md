# Localisation rules

Consult `https://www.i18next.com/llms.txt`. `messages.yaml` is the source of truth; CI compiles per-locale JSON.

- Workflow: edit `messages.yaml`, run `pnpm i18n:build`, commit `src/generated/` with it (CI fails on drift, like the OpenAPI types). `packages/i18n/README.md` has the steps; `docs/i18n/tone.md` and `glossary.yaml` are the voice and the vocabulary.
- Keys are semantic (`profile.bio.required`), never the English text. Each key has `en`, a `description`, and `fi`; `sv` once a native reviewer exists.
- `t()` is typed; a missing key, a missing ICU argument or a wrong argument type is a type error. Clients use `useT()` from `@kuutti/i18n/react`; the API uses `c.get("t")`. `pnpm lint` fails on a string literal in JSX text, as a JSX child, or in a prop that is read or heard (`accessibilityLabel`, `placeholder`, `title`, `closeLabel`, ...) in the clients' TSX. The API localises from this package using the account's stored locale (push, moderation notices, receipts, errors).
- Fallbacks: fi to en, sv to en. ICU plurals from day one. Dates and numbers through Intl.
- Never inflect dynamic values. Proper nouns and user values appear only in nominative positions; case forms for ponds are stored per pond in the database. The pattern `in {pond}` is banned.
- `pnpm i18n:translate` fills missing fi and sv keys by machine with `machine: true`; a native reviewer clears the flag (`--review` lists them). Text an agent writes in fi or sv is machine text too and carries the flag. CI: missing fi fails, missing sv warns, unreviewed fi blocks a release tag and a production build (`pnpm i18n:check --release`). `admin.*` is English only. The translator receives message text, the glossary and the tone guide, never anything from a database.
- Never machine-translate the privacy policy, consent texts, terms, or the police-traceability line. They are versioned by `consent_version` and the Finnish text is binding.
- Finnish runs about 30% longer than English; the `en-XA` pseudo-locale exists to catch overflow in dev builds.
